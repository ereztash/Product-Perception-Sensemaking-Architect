# Agent Discovery — Broad Discovery Closeout

Status: `BROAD_DISCOVERY_CLOSED_AT_SATURATION · NO_NEW_AGENT_EARNED · TARGETED_ARCHITECTURE_TEST_REMAINS`
Date: 2026-09-06

## Research question

Which recurring material judgment functions remain unowned after subtracting:
- Neta;
- R&D;
- OWNER/REPO/ENVIRONMENT/RESEARCH/FIELD authorities;
- domain methods;
- deterministic coordination/protocol;
- execution/tools;
- shared evidence/lineage infrastructure?

And, for any residual, what is the cheapest durable form that preserves the judgment?

## Broad result

No new peer is currently earned.

This is not a claim that the system is complete forever. It is the result of the current evidence and the frozen admission rule.

### Current justified peer layer

1. `NETA`
   - domain method;
   - product perception/design sensemaking;
   - signal → competing mechanisms → discriminator → evidence-bounded intervention.

2. `R&D`
   - cross-cutting method;
   - strongest current scope candidate: consequential decision + separable nontrivial choice whether/how/how much to invest in learning/evidence;
   - still under scope confirmation, but no newly researched capability displaced it.

### No third peer earned

Broad search, external completeness checks, natural historical screens and targeted falsification did not establish another recurring orthogonal judgment with comparative decision delta.

## Candidate findings

### Architecture

`STATUS = CANDIDATE_CAPABILITY_NOT_AGENT`

Distinct judgment is plausible and well specified:

```text
VALIDATED REQUIREMENTS / CONSTRAINTS / INVARIANTS
+ CURRENT SYSTEM FACTS
→ STRUCTURAL OPTIONS
→ DEPENDENCY / FAILURE / CHANGE / MIGRATION TRADEOFFS
→ BOUNDED ARCHITECTURE DECISION
```

The front-door transformation from accepted need to architecture-significant required properties is real, but current evidence does not justify a separate Requirements capability. Generic upstream qualification already produced the material reframe in natural cases such as Sheet-as-source-of-truth.

Best current form for the front door:
`ARCHITECTURE_INPUT_GATE`, not a new agent.

The unresolved promotion question is only whether the **structural discriminator itself** adds material delta beyond the strongest existing baseline.

### Decision Support / Tradeoff Structuring

`STATUS = PLAUSIBLE_BUT_RECURRENCE_NOT_OBSERVED`

External decision-analysis doctrine shows a coherent possible function:

```text
explicit OWNER criteria
+ feasible alternatives
+ bounded current information
→ consequences / tradeoffs
→ ranking robustness
→ recommendation
→ OWNER commitment
```

But natural screening found only one clean positive-looking case. Most apparent examples collapsed into:
- R&D because the next move was evidence-generating;
- OWNER because values/policy were missing;
- domain method because specialized judgment controlled;
- dominated/simple choices.

No capability or agent is earned.

Reopen only after >=5 natural admissible post-OWNER cases across >=3 domains survive the exclusion rule.

### Need → Architecture Requirement Translation

`STATUS = REAL_TRANSFORMATION · BEST_AS_CONTRACT/GATE`

Natural Sheet/Vercel cases support the need to surface required properties/invariants before structural commitment. They do not show unique reasoning beyond current upstream qualification.

Do not create `Requirements Agent`.

### Orchestrator

`STATUS = NOT_EARNED`

Calibration Loop + machine-readable handoff already own routing/dependency state deterministically. No recurring coordination failure family demonstrates a need for learned orchestration.

### Execution

`STATUS = NOT_EARNED`

Decision → execution → verified state → outcome → learning is currently a trace/authority/tooling problem. No corpus of 10–15 real traces shows a recurring residual judgment after planning and verification contracts are present.

### Verification / Validation

`STATUS = AUTHORITY, NOT PEER`

REPO/ENVIRONMENT/FIELD establish reality. A reasoning method may design a verification plan but cannot create truth authority by becoming an agent.

### Debugging

`STATUS = DOMAIN_METHOD`

The R&D external scope test already supplied a negative control: multiple technical hypotheses and sequential tests can remain ordinary debugging. Complexity does not make a new peer.

### Applied Epistemology / VOI

`STATUS = R&D THEORY / EVAL LENS`

Controlled challengers improved vocabulary/contract clarity but did not establish unique next-move capability beyond current R&D.

### Question Discovery

`STATUS = FRONT_DOOR BEHAVIOR / GATE`

Useful upstream qualification is real, especially when the named unit of investment is premature. Separate epistemic capability was not shown beyond R&D + Neta + routing.

### Strategy

`STATUS = OWNER AUTHORITY + SUPPORT METHODS`

Telos, legitimate values, accepted risk and final commitment remain OWNER-owned. No independent Strategy-agent judgment was isolated.

### Risk

`STATUS = CROSS-CUTTING MODIFIER`

Risk changes evidence thresholds, architecture tradeoffs, reversibility and owner acceptance. No separate residual judgment currently earns a peer.

### Memory

`STATUS = INFRASTRUCTURE`

Provenance, supersession, trace and recovery are durable system requirements, not evidence for a reasoning peer.

## Convergence check

An earlier independent repo trace, `CAL-MECE-001.trace.json`, had already reached the same structural default:

- retain Neta and R&D as the only justified reasoning peers;
- do not add a generic third peer;
- treat execution/state-change and outcome observation as explicit non-agent functions;
- keep Architecture as the only current peer candidate until unique comparative decision delta is shown.

The present Agent Discovery program reached that conclusion through a stricter residual/function/form-factor protocol and added two useful refinements:

1. `cross-cutting peer` vs `domain peer` are different peer families;
2. `domain diagnostic branching` and `need→requirements translation` must not be mistaken for new agents merely because they contain difficult reasoning.

This convergence strengthens the current default but is not independent statistical evidence because the artifacts share project lineage.

## Only authorized high-value next test

### Clean Architecture comparative delta

Question:

> Does the Architecture Decision Discriminator materially improve structural decisions beyond the strongest current ecosystem baseline?

Comparison:

```text
A = R&D + Scaffold + relevant REPO/ENVIRONMENT/OWNER facts
B = A + minimal Architecture Decision Discriminator
```

Use cases where structural judgment is genuinely live, plus neighboring controls where:
- direct authority settles the issue;
- requirement translation is still incomplete;
- ordinary debugging is primary;
- one structural option is already dominated;
- the decision is low/local.

A win must change at least one materially:
- structural option selected/eliminated;
- invariant/boundary surfaced;
- dependency/failure-domain treatment;
- migration/reversal plan;
- evidence/authority handoff;
- build/defer decision.

Terminology or better architecture prose is not a win.

## Stop / reversal rules

Do not add another peer unless new evidence shows a recurring residual outside the map.

Reopen broad discovery only if:
- a real decision repeatedly fails despite correct Neta/R&D/domain/authority routing;
- deterministic protocol/tool repair is insufficient;
- the same hidden judgment recurs across cases;
- a minimal candidate changes material decisions over the strongest existing system.

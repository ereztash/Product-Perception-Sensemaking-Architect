# CAL-RND-EPISTEMOLOGY-001 — Epistemology expertise capability test

Status: `FROZEN_BEFORE_SYNTHESIS · REPO_GROUNDED · EXTERNAL_RESEARCH_ALLOWED`
Date: 2026-09-06

## Decision

Should R&D acquire an explicit epistemology expertise layer because it materially improves its ability to calibrate epistemic effort to decision value?

## Current candidate R&D telos

> Make epistemic effort proportional to the uncertainty that can still change a consequential decision.

Operationally: identify decision-controlling uncertainty, choose the cheapest admissible learning/evidence channel, observe decision delta, and stop when further learning no longer justifies its cost.

## Competing hypotheses

### H0 — Vocabulary-only
The current Shared Epistemic Kernel + R&D already contain the decision-relevant distinctions. Epistemology adds names/history but no repeated material decision delta.

### H1 — Broad-domain upgrade
General expertise in epistemology adds material decision distinctions across a broad range of R&D tasks and deserves explicit capability representation.

### H2 — Targeted-subdomain transfer
Broad epistemology is too large. A small set of epistemological sub-capabilities adds repeated material decision delta and should be transferred selectively.

## Candidate external capability families

1. evidence / justification / epistemic basing / defeat;
2. higher-order evidence / epistemic self-doubt;
3. reliabilism / process reliability;
4. testimony / expertise / peer disagreement / social epistemology;
5. underdetermination / abduction / hypothesis-set incompleteness;
6. epistemic and inductive risk;
7. Bayesian epistemology / credence updating;
8. epistemic utility / value of knowledge.

## Material-delta criterion

A candidate counts as useful only if it can repeatedly change at least one of:

- which uncertainty is treated as decision-controlling;
- which evidence/learning channel is selected;
- whether a source/process/result is trusted enough for the requested use;
- claim state or confidence/credence discipline;
- evidence threshold given error consequences;
- whether disagreement/reliability evidence changes a conclusion;
- whether an explanation is treated as discriminated vs merely best among sampled candidates;
- continue / change-channel / stop;
- whether a reusable method deserves reuse/adaptation/retirement.

Vocabulary, intellectual elegance, source volume, or retrospective fit do not count.

## Existing repo baseline to protect

Already represented:
- claim/evidence/provenance objects;
- resolution authority;
- requested use and permission separated from confidence;
- null/inconclusive/refuted/pending distinctions;
- independent-lineage requirement;
- falsification and reversal conditions;
- cheapest decision-changing learning;
- research vs TEST/REPO/ENVIRONMENT/FIELD/WAIT/STOP;
- observed decision delta;
- stopping when more learning cannot change the decision.

## Required research sequence

1. map external epistemology distinctions to current repo capability;
2. classify each as `ALREADY_PRESENT`, `PARTIAL`, or `ABSENT`;
3. test only PARTIAL/ABSENT candidates on controlled decision cases;
4. invoke Neta to challenge proxy/mechanism collapse before recommending an R&D capability change;
5. choose `NO_CHANGE`, `TARGETED_TRANSFER`, or `BROAD_EPISTEMOLOGY_LAYER`;
6. name falsifier and cheapest next validation.

## Promotion bar

Do not modify canonical R&D or Shared Epistemic Kernel from this research pass alone.
A transfer candidate requires:
- a unique decision distinction;
- at least one positive case;
- a neighboring non-fire case;
- no duplication of Neta/OWNER/authority functions;
- a falsifiable unseen benchmark path.

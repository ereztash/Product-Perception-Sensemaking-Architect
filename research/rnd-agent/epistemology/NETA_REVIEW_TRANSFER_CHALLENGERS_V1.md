## Raw signal

The comparative run found no clean behavioral win for targeted epistemology or applied epistemology, while VOI supplied a clearer ranking doctrine but not yet a natural-case behavioral win.

## Observable

The applied-epistemology positive cases explicitly exposed the omitted evidence or compromised inquiry structure:
- AE-01 tells us exit interviews mention manager behavior/scheduling;
- AE-02 tells us new users are the abandonment population;
- AE-03 tells us apparent experts share a consultancy memo;
- AE-05 tells us activation has never been inspected.

Therefore current R&D did not have to *discover an excluded relevance class*. It only had to respect an already-visible one.

## Candidate mechanisms

### M1 — Applied epistemology adds no capability

Current R&D already owns telos, bottleneck, authority, provenance and cheapest decision-changing learning. Applied epistemology merely names these behaviors.

Prediction: even when the relevance defect is latent rather than stated, current R&D will generate the necessary alternative inquiry frame at the same rate/cost as an applied-epistemology challenger.

### M2 — Benchmark aliasing hides an inquiry-generation gap

Current R&D can repair a frame once an excluded variable is visible, but may not systematically ask whether the inherited relevance filter itself is incomplete.

Applied epistemology could add a distinct probe:

> What potentially decision-relevant evidence, actors or alternative frames are excluded by the way this inquiry is currently posed?

Prediction: on under-specified natural cases, the applied challenger surfaces omitted relevance classes more reliably before buying research.

### M3 — The residual belongs to a different capability

Generating missing alternative frames may be broad decomposition / Neta / external scaffold rather than R&D-specific applied epistemology.

Prediction: applied-epistemology prompting appears to help only because it acts as a generic creativity/alternative-generation scaffold, not because of a stable epistemic distinction.

## One discriminator

Do not test more cases where the omitted variable is named.

Freeze cases in which:
- the inherited inquiry frame is plausible and internally coherent;
- evidence inside the frame can be high quality;
- the omitted relevance class is not explicitly supplied;
- an independent gold rationale can identify a materially different frame from task/context evidence;
- neighboring cases exist where reopening the frame would add unnecessary ceremony.

Compare:
1. CURRENT_RND;
2. CURRENT_RND + one minimal `EXCLUDED_RELEVANCE_CHECK`;
3. broad external scaffold / alternative-generation control.

Applied epistemology earns a distinct transfer only if (2) beats (1) without merely matching the generic breadth of (3).

## Neta interpretation of VOI

VOI's stronger signal is structurally different. It does not depend on generating a hidden mechanism; it supplies a decision rule over already represented learning options.

This makes it easier to isolate:

```text
OPTIONS ALREADY KNOWN
→ CURRENT_RND ranking
vs
→ VOI ranking
```

Therefore VOI remains the cleaner next capability test.

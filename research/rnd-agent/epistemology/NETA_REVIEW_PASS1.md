## OBSERVABLES

1. R&D's current repo already contains many applied-epistemic distinctions before this external literature pass.
2. External epistemology provides close conceptual matches for several existing rules.
3. The controlled ablation found no clean epistemology-only next-move delta across seven cases once current kernel + R&D + Neta routing are respected.
4. External concepts sharpened several hidden judgments: higher-order evidence, epistemic risk, underdetermination/abduction, basing lineage.
5. The clearest material doctrinal ambiguity surfaced from Value of Information / decision analysis, not from epistemology proper.

## Competing interpretations

### M1 — `R&D NEEDS EPISTEMOLOGY EXPERTISE`
The external field contains missing competence that should be added as a broad capability.

Explains:
- strong semantic fit between the agent's behavior and epistemological concepts.

Does not explain:
- why most tested distinctions already exist operationally;
- why broad transfer produced no clean unique decision delta.

### M2 — `R&D HAS CONVERGED ON APPLIED EPISTEMIC PRINCIPLES`
The repo independently discovered practical epistemic distinctions through decision failures; academic epistemology now supplies theory, vocabulary and adversarial edge cases.

Explains:
- strong conceptual convergence;
- limited broad capability delta;
- value of targeted concepts as tests/repairs rather than a new peer.

### M3 — `THE CORE IS HYBRID: EPISTEMOLOGY + DECISION ANALYSIS`
Epistemology constrains what should count as justified/reliable evidence; decision analysis determines how much information is worth buying for a decision.

Explains:
- why R&D's candidate telos is about `epistemic effort` rather than knowledge for its own sake;
- why VOI is especially close to `which uncertainty is worth paying to reduce?`;
- why evidence authority/reliability and information value are distinct judgments.

## Discriminator

The next test must not ask whether epistemology sounds relevant.

Create unseen cases where:
- current R&D and an explicit epistemology rule make different predictions;
- both predictions are allowed by current evidence;
- the difference changes a real next move / claim state / threshold / stop decision;
- a neighboring non-fire case prevents generic caution from winning automatically.

If no such recurring cases can be found, epistemology is theoretical support, not a missing capability.

For VOI, run a separate comparator because otherwise an improvement from decision analysis may be falsely attributed to epistemology.

## Neta distinction

> **Conceptual resemblance is not causal ownership.**

The fact that an academic discipline has names for the distinctions does not show that importing the discipline caused or will improve those distinctions.

Do not collapse:

```text
R&D behavior resembles epistemology
≠
R&D requires broad epistemology layer
```

Also do not collapse:

```text
Epistemology validates evidence norms
≠
Epistemology tells us which uncertainty is economically worth resolving
```

The latter is partly a decision-analysis / VOI question.

## Candidate product-level interpretation

The stronger discovery may be that R&D is not a generic research agent at all. It is a practical **learning-investment calibration method** whose competence boundary crosses:

```text
EPISTEMOLOGY
— what counts as justified/reliable support?

PHILOSOPHY OF SCIENCE / METHODS
— what observation discriminates hypotheses?

DECISION ANALYSIS / VOI
— which uncertainty is worth paying to reduce?

AUTHORITY / REALITY
— who or what can legitimately close the claim?
```

This is a mechanism hypothesis, not permission to add four new agents or a broad knowledge layer.

## Decision before

## Evidence

### Targeted epistemology

Visible adversarial cases produced no clean next-move delta beyond current R&D + kernel/Neta. Higher-order defeat, basing lineage, epistemic risk and underdetermination materially sharpened the hidden judgment but did not alter the path in the tested cases.

Disposition:
`CONCEPTUAL_HYGIENE_STRONG · BEHAVIORAL_TRANSFER_NOT_EARNED`

### Applied epistemology

External literature adds a potentially important object: the *line of inquiry* and what is treated as relevant to a question can itself be epistemically evaluated. A process can collect accurate evidence while being malformed by its relevance frame.

In the visible adversarial cases, however, current R&D already reopened bad frames via TELOS → BOTTLENECK → decision-changing learning.

Neta identified benchmark aliasing: every positive case explicitly exposed the omitted variable / excluded population / shared mediation. Current R&D only had to respect a visible defect; it did not have to discover an excluded relevance class.

Therefore the correct disposition is not a full negative:

`VISIBLE_RELEVANCE_REPAIR: ALREADY_COVERED`

`LATENT_INQUIRY_FRAME_DISCOVERY: UNRESOLVED`

Minimal candidate rule for future testing:

> Before buying more evidence inside the current inquiry, ask whether the inherited frame excludes any plausibly decision-changing evidence class, actor, mechanism or alternative question.

This rule earns transfer only if it beats current R&D on latent-frame cases without becoming generic “consider everything” ceremony and without merely duplicating a broad scaffold.

### Value of Information

VOI remains the clearest doctrinal delta. Current R&D contains both expected decision value and `cheapest decision-changing learning`, but no explicit ranking law for conflicts between low-cost/low-value and higher-cost/high-value learning.

Candidate:

> Prefer the admissible learning move with the highest expected decision improvement net of acquisition, delay and contamination cost; when incremental decision value is materially equivalent or a decision threshold is already crossed, choose the cheapest sufficient move.

The visible test closed a doctrine ambiguity but did not yet establish that current R&D makes a different wrong natural-case choice.

Disposition:
`DOCTRINAL_DELTA_ESTABLISHED · NATURAL_BEHAVIORAL_DELTA_UNRESOLVED`

## What applied epistemology changes in the intellectual map

The emerging R&D function is now externally convergent with at least four neighboring literatures:

```text
EPISTEMOLOGY
  justification / defeat / reliability / disagreement

APPLIED EPISTEMOLOGY / INQUIRY
  relevance framing / testimony / expertise / collective inquiry / situated evidence

PHILOSOPHY OF SCIENCE & METHODS
  falsification / discrimination / underdetermination

DECISION ANALYSIS / VOI
  which uncertainty is worth paying to reduce / when to stop
```

This strengthens `EPISTEMIC_EFFORT_CALIBRATION` as an intellectual description, but does not justify importing all four fields into the agent prompt.

## Current strongest hypothesis

> R&D's unique core is not “research” and not generic “resource allocation”. It calibrates inquiry/learning effort against decision value under evidence, authority and relevance constraints.

The applied-epistemology result suggests one possible missing sub-operation before evidence allocation:

```text
DECISION
→ INQUIRY FRAME / RELEVANCE CHECK ?
→ DECISION-CONTROLLING UNCERTAINTY
→ LEARNING OPTIONS
→ VOI / SUFFICIENCY
→ EVIDENCE ACQUISITION
→ DELTA
→ CONTINUE / STOP
```

The question mark is deliberate: `INQUIRY FRAME / RELEVANCE CHECK` is not yet earned.

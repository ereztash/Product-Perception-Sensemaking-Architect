# Neta Review — R&D Scope Decomposition

Status: `ROLE_CONDITIONED_MANUAL_NETA_REVIEW · NOT_INDEPENDENT_VALIDATION`
Date: 2026-09-06

## RAW SIGNAL

> Find the boundaries inside which R&D gives the most value, without allowing R&D to define a self-confirming territory.

## OBSERVABLE

The current candidate telos and prior experiments repeatedly cluster around:
- live consequential decisions;
- uncertainty that can still alter the decision;
- choosing whether/how/how much to learn;
- evidence/authority selection;
- continue/change-channel/stop;
- strict peer/authority boundaries.

However many attractive labels (`wrong relevance structure`, `higher-order defeat`, `VOI`, `decision-controlling uncertainty`) are partly *diagnostic outputs*. If used as input categories, the benchmark can become circular.

## Competing scope decompositions

### Candidate A — method-derived feature soup
Use all current R&D concepts as axes: uncertainty, VOI, inquiry frame, contamination, authority, reuse, phase, etc.

What it explains: rich local differences.
What it risks: categories are generated from R&D's own doctrine, creating apparent fit by construction.

### Candidate B — authority-first decomposition
First classify by legitimate resolution authority; test R&D only inside RESEARCH/epistemic tasks.

What it explains: protects peer boundaries.
What it misses: R&D often decides *which authority/evidence channel should be paid*, so a pure authority-first split can erase one of its useful decisions.

### Candidate C — pre-outcome structural decomposition
Use only features codable before seeing R&D's answer:

1. **DECISION CONSEQUENCE**
   - `LOW/LOCAL`
   - `MATERIAL/CONSEQUENTIAL`

2. **EPISTEMIC ALLOCATION BURDEN**
   - `NONE` — no unresolved learning choice; direct execution/fact/owner intent.
   - `OBVIOUS` — one cheap/reversible/legitimate discriminator dominates.
   - `NONTRIVIAL` — two or more non-equivalent learning/evidence moves differ in authority, cost, delay, validity or decision reach.

3. **RESOLUTION STRUCTURE**
   - `SINGLE_DIRECT_AUTHORITY` — a known OWNER/REPO/ENVIRONMENT/FIELD answer can directly resolve the live question.
   - `CHANNEL_SELECTION_REQUIRED` — deciding which evidence/authority channel to invoke is itself unresolved.
   - `RESEARCH_METHOD_REQUIRED` — external empirical/research method must be selected or validated.

4. **LEARNING PHASE**
   - `PRE` — choose whether/what/how to learn.
   - `MID` — evidence arrived; choose update / another iteration / channel change.
   - `POST` — decide reuse, retirement, generalization or whether the method deserves future invocation.

This is the strongest candidate because the axes are observable before outcome and are not identical to the success labels.

## Modifiers, not primary axes

Treat these as modifiers unless evidence shows they create independent boundary effects:
- reversibility;
- direct cost;
- delay;
- contamination/reactivity;
- reusable policy vs one-off action;
- evidence lineage quality.

They can amplify consequence or make allocation nontrivial, but making each a primary axis will explode the cell count and destroy confirmatory power.

## Explicit exclusions / neighbor ownership

Do not let the benchmark define R&D as valuable merely because a case is hard.

### Neta-owned primary cases
When the core unresolved object is:
`RAW PRODUCT SIGNAL → COMPETING PRODUCT/DESIGN MECHANISMS → DISCRIMINATOR → INTERVENTION`
R&D may support evidence planning, but Neta is the comparator / primary peer.

### OWNER
Settled intent, preferences and accepted tradeoffs are not R&D territory.

### REPO / ENVIRONMENT / FIELD
When one direct authority can answer the exact live state/reality question and the method of obtaining it is obvious, R&D should not add ceremony.

### EXECUTION / ORCHESTRATION
Once the epistemic path is justified and the remaining work is execution/coordination, R&D should stop.

## ONE DISCRIMINATOR

The cleanest hypothesis is not `R&D is valuable on research tasks`.

It is:

> **R&D should add its highest marginal value when a consequential decision remains open AND the system faces a nontrivial choice about whether/how/how much to learn before the decision can be responsibly advanced.**

The nearest negative neighbor is:

> consequential decision + uncertainty exists, but one direct legitimate authority or one cheap reversible discriminator obviously dominates.

If R&D adds equal value in the neighbor, the proposed scope is too broad.

## Evaluation warning

`UNCERTAINTY_CAN_CHANGE_DECISION` should not be coded from R&D's explanation alone. The case author/adjudicator must freeze the live decision and plausible reversal outcomes before seeing R&D output.

Likewise `NONTRIVIAL` should be coded from the case setup: at least two admissible learning routes whose relative value is genuinely unresolved, not because R&D later invented alternatives.

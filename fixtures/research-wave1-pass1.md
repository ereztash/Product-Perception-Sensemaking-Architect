# Wave 1 research fixtures — pass 1

These fixtures operationalize the first external triangulation pass. They do **not** authorize prompt changes. Their purpose is to make each candidate capability discriminable before any attempt to teach it to Neta.

## R-W1 · Tacit → explicit without planting the answer

**Owner signal:** "זה מרגיש כאילו כל לחיצה פה דורשת ממני לחשוב יותר מדי."

**Bad collapse:** "זו בעיית cognitive load."

**Required discrimination:** ask for the concrete moment/action/expectation before supplying a causal design label. Keep simple description separate from directed explanation.

**Discriminator:** compare what the owner can describe before terminology is introduced with what appears only after the label is suggested.

**Reversal:** if the same distinction is independently articulated before the vocabulary is introduced across repeated cases, suggestion is not needed to explain that distinction.

---

## R-W2 · Too much information vs weak hierarchy/grouping

**Owner signal:** "יש פה יותר מדי דברים."

Variant A: 14 elements, clearly grouped into one current task plus disclosed secondary material.

Variant B: 7 elements, all same visual weight, spacing and border language.

**Bad collapse:** fewer elements must be better.

**Required discrimination:** quantity and perceptual organization remain separate candidate mechanisms.

**Discriminator:** hold content quantity constant while changing grouping/rank; then hold hierarchy constant while changing quantity.

**Reversal:** if quantity reduction changes the complaint while hierarchy-preserving manipulations do not, hierarchy is insufficient to explain the complaint.

---

## R-W3 · "Windows XP" is not a usability diagnosis

**Owner signal:** "זה נראה כמו Windows XP."

Two surfaces have identical task flow and measured completion performance. One uses an orderly but visibly dated visual language; the other uses a contemporary but expressive/irregular language.

**Bad collapse:** old-looking = unusable; or aesthetic complaint = mere taste and can be ignored.

**Required discrimination:** preserve perceived craft/modernity, classical order/clarity, expressive aesthetics and task usability as separate constructs.

**Discriminator:** ask whether the complaint survives a skin-only transformation and whether task legibility changes independently.

**Reversal:** if changing visual language alone does not change the owner's complaint, perceived modernity/craft is not sufficient.

---

## R-W4 · "The button doesn't respond"

A click handler completes in 70 ms. The button shows no pressed/loading/success state and the resulting content change occurs below the fold.

**Bad collapse:** latency is fine, therefore responsiveness is fine.

**Required discrimination:** actual completion latency, acknowledgement, progress/wait status and state-transition salience are separate.

**Discriminator:** timestamp action→acknowledgement and action→completion separately; inspect whether the resulting state is perceptually discoverable.

**Reversal:** if acknowledgement is immediate and salient and completion is fast while the complaint persists, feedback latency is insufficient.

---

## R-W5 · Less is not automatically cognitively cheaper

A user is making a high-stakes evidence decision. Variant A shows one verdict with no rationale. Variant B shows the verdict, a concise rationale, evidence trace and a closed disclosure for details.

**Bad collapse:** Variant A must be better because it contains less information.

**Required discrimination:** separate extraneous interaction cost from information needed for comprehension, trust calibration and the task itself; account for expertise.

**Discriminator:** identify which information is necessary to complete/defend the task and which processing is imposed only by presentation.

**Reversal:** if added evidence/rationale does not improve task-relevant understanding or decision quality and only raises effort, the added information is not justified for that state.

---

## R-W6 · One primary action is mode-conditional

Variant A is an execution state: the user has already chosen a goal and must submit one decision.

Variant B is an exploration state: the user's explicit task is to compare three legitimate routes before choosing.

**Bad collapse:** both screens must expose exactly one selectable option.

**Required discrimination:** one-primary-action is strong in execution with a dominant task; exploration/choice can legitimately expose alternatives when comparison is the task. Option cost depends on choice complexity, preference uncertainty and goal.

**Discriminator:** classify the interaction mode and ask whether alternatives are the task or competitors to the task.

**Reversal:** if external users in an execution state benefit from peer-weight alternatives without slower/poorer decisions, the one-primary-action intervention is not justified there.

---

## R-W7 · Trust is not the target variable

An AI recommendation is accompanied by a polished explanation. Users report higher trust, but the recommendation is wrong and behavioral reliance increases.

**Bad collapse:** higher trust means the explanation worked.

**Required discrimination:** subjective trust, behavioral reliance, output accuracy, evidence quality and action authority remain separate.

**Discriminator:** compare trust ratings with correctness-sensitive reliance and whether users appropriately deviate when evidence is wrong/weak.

**Reversal:** if added explanation improves discrimination between correct and incorrect outputs rather than merely increasing reliance, the explanation may improve calibration in that context.

---

## R-W8 · A useful question can contaminate the thing it measures

Before a chess decision, the product can ask: "Which second move were you considering?" The answer would distinguish candidate-generation failure from evaluation failure, but asking it may change the move search itself.

**Bad collapse:** more diagnostic information is always worth collecting.

**Required discrimination:** expected information gain, response burden and measurement reactivity are separate costs/benefits. Measurement and intervention must not silently change together.

**Discriminator:** state which hypotheses the probe separates and whether the probe occurs before, during or after the behavior whose natural form matters.

**Reversal:** if the probe produces no meaningful discrimination between live hypotheses, or measurably changes the target behavior enough to invalidate the original question, remove/defer it.
